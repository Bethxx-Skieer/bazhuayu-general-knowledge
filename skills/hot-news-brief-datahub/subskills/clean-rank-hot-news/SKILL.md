# 清洗热点新闻候选

## Mission

形成当前任务唯一可进入价值评估的候选集合。

## When to use

全部计划批次结束，或服务故障但至少保留了一个可用终态批次后执行。

## Hard constraints

- 只处理成功或部分成功批次中的记录。
- 必须有标题、已解析 HTTP(S) 原文 URL 和有效发布时间；排除未来日期和 7 天外记录。
- `url.sz.dataduoduo.com` 等跳转域名不得充当原文来源；未解析记录排除。
- 清除跟踪参数，规范 URL，去重转载，每域名最多 2 条。
- 排除导航、广告、低相关、低可信和敏感内容；候选最多 40 条。
- 不处理 DataHub 账单、费用、余额或额度字段。

## Core workflow

合并可用批次，依次执行字段、时间、原文 URL、相关性、来源、规范 URL 和故事去重门禁。

## Output format

向根 Skill 返回最多 40 条候选及原始数、有效数、去重数、来源分布和排除原因。

## Done criteria

- 候选标题、原文 URL、来源和日期均来自同一 DataHub 记录。
- 无重复故事、超期内容、未解析跳转链接或客户不可见字段。
